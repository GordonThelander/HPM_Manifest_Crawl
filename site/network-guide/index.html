Evidence model

Four labels, four different meanings

Stronger wording requires stronger evidence.

Declared

Publisher tags

LAN or Cloud tags supplied in the HPM repository. Useful classification, not independently verified architecture.

Observed

Static source signals

Literal external hosts and Hubitat LAN primitives found in fetched source. A code path may be optional, inactive or only an example.

Documented

Official documentation

Links attached to reviewed Automation Map records. Documentation describes behaviour but may change over time.

Reviewed

Dependency conclusions

Human-reviewed Automation Map dependencies, consumed read-only and never inferred from HPM tags alone.
