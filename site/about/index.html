How the site works

From public sources to static utilities

Collection, validation and publication remain separate from Automation Map.

The project acquires bounded public evidence, validates its shape and provenance, builds independent projections, then publishes static browser-only utilities. Automation Map uses a separate protected registry that the general projections cannot broaden or rewrite.

Status is operational evidence, not a score. Healthy means a retained snapshot validates. Degraded means usable evidence includes explicit gaps. Stale means the latest retained success is old. Unavailable means no valid retained snapshot is present. Manually reviewed means a maintainer confirmed the public evidence. None of these labels certifies software quality, maintenance, safety or trust.
Aggregate site analytics. The published site uses Cloudflare Web Analytics to count visits and understand page performance. It does not receive hub configuration, device names, app settings or search terms entered into these browser-local tools.
