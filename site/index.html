How it helps

Useful answers with links back to the source

  • Find the original source. Package, repository, documentation and community links stay close to each result.
  • See when information changed. Daily updates build a practical history of the HPM catalogue.
  • Compare different sources. HPM, Hubitat documentation and community listings remain clearly identified.
  • Keep Automation Map stable. Its reviewed integration registry remains separate from these broader catalogues.
