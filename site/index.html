Built with restraint

What the evidence can - and cannot - say

  • URLs are observations. They are not automatically runtime dependencies.
  • Failed links are time-bound results. They do not prove a project is abandoned.
  • Missing metadata is an absence. It is not automatically a package defect.
  • Automation Map stays independent. These general datasets never broaden its reviewed runtime registry.
