Evohome

Connects Hubitat Elevation to Honeywell/Resideo Evohome. Creates heating-zone thermostats, a system-mode controller and a hot-water device when available. Supports HomeKit zone control, debounced setpoint changes, status polling and reconciliation, Hubitat Away synchronisation, per-zone override preservation, window-contact protection, fault reporting and push notifications. Includes heating-only support and automatic API token renewal.
