Daikin HVAC Split Manager

<b>Daiken Split Manager</b> is a native Parent App and Child Device Driver suite for Hubitat Elevation that provides 100% local monitoring and control of Wi-Fi-enabled Daikin mini-split indoor units using Daikin's local <code>/dsiot/multireq</code> JSON API (DGC protocol) - with <b>no cloud dependency</b> and <b>no Home Assistant or MQTT middleware</b> required.
