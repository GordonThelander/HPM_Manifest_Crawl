X-Sense Smoke/CO Detector Integration

Complete Hubitat integration for X-Sense smoke and CO detectors (SC07-MR and compatible models) via the SBS50 bridge. Features AWS Cognito SRP authentication, AWS IoT Shadow API for device status, configurable polling intervals, and automatic child device creation.
