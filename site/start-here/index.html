The basic picture

Three parts of the ecosystem

Knowing who provides the software helps you interpret what the site can confirm.

  1. 1

    Hubitat platform and built-ins

    Hubitat supplies the hub platform plus built-in apps and drivers. Official device listings and release notes are evidence published by Hubitat.

  2. 2

    Community apps and drivers

    Community developers publish optional code. An app adds automation behaviour. A driver lets the hub communicate with a device or service.

  3. 3

    Hubitat Package Manager

    HPM helps install and update participating community projects. Being listed in HPM describes distribution, not Hubitat approval or a safety guarantee.

How to read the results

The labels describe the strength and source of the evidence. They are more important than colour.

Exact

Identity confirmed

The identifying fields agree. When a result is only similar, it is labelled as a suggestion instead.

Source

Origin stays visible

Official, HPM, community wiki, source-code and reviewed evidence are kept separate because they answer different questions.

Snapshot

Observed at a point in time

A crawl snapshot is a dated library inventory. New successful snapshots let the site show changes without losing the previous good record.

Health

Operational evidence only

A failed link or degraded source records what a check observed. It does not prove code is unsafe, abandoned or unsuitable.

No match

Absence is not proof

Not finding a package can mean it is manual-install only, renamed, missing from a catalogue or identified differently.

Privacy

Public data, local searches

The browser tools do not need device names, rooms, rules, tokens, app settings or other household configuration.

Small glossary

These are the terms you will see most often.

App
Code that adds automation logic or a user-facing integration.
Driver
Code that represents and communicates with a device or service.
Package
A bundle of one or more apps and drivers that can be distributed together.
Manifest
A JSON file telling HPM what one package contains and where its files are located.
Repository
A separate JSON file an author hosts listing every package they publish. HPM reads it when you add a custom repository, and its public location is what gets listed in HPM's own catalogue.
Namespace
A developer-chosen identity used with a definition name to distinguish Hubitat code.
Snapshot
A validated record of public catalogue evidence observed at a specific time.
