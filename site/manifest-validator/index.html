4 · Publish

Public HPM submission

Prepare the two catalogue entries; you remain in control of the pull request.

HPM does not install a package directly from its manifest URL. It reads a repository.json that lists every package you publish and points to each one's manifest, either from your own custom repository or, once merged, from the community's public repositories.json. Enter your repository.json's public URL below; this tool then generates the entry to add inside it, plus the separate name-and-location entry needed for the public repositories.json.
